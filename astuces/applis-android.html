Des applis Android utiles, sans Play Store douteux

Le Play Store n’est pas le seul magasin, mais tous les APK ne se valent pas. L’open source est un bon point de départ.

F-Droid, le magasin open source

F-Droid ne propose que des applications open source, sans publicité ni traqueurs intégrés. L’installation se fait via son site officiel, puis le magasin gère les mises à jour.

Le catalogue est plus restreint et les mises à jour arrivent parfois moins vite, mais la transparence est bien meilleure que sur les sites d’APK.

Quelques applis solides

  • Signal : messagerie chiffrée, sans dépendance à un géant du web.
  • KeePassDX : gestionnaire de mots de passe local, compatible avec les bases KeePass.
  • Aegis : codes de double authentification, avec export chiffré.
  • Organic Maps : cartes hors ligne, sans traqueur.
  • AntennaPod : podcasts, sans compte ni publicité.
  • Termux : terminal Linux pour les curieux, à manipuler avec prudence.
Règle de sécurité : aucune application bancaire installée depuis un APK. Pour l’argent, le magasin officiel et les mises à jour automatiques.

Installer un APK sans risque

Télécharge uniquement depuis le site officiel du projet ou sa page GitHub Releases. Un APK trouvé sur un forum, modifié pour « débloquer des fonctions », peut contenir n’importe quoi.

Vérifie les permissions demandées et l’éditeur. Une application de lampe torche qui demande l’accès aux contacts n’a aucune raison de le faire.

Les limites à connaître

Certaines applications bancaires ou de paiement refusent de fonctionner sur un appareil rooté ou avec des APK non officiels. Dans ce cas, utilise le magasin officiel.

Les mises à jour manuelles sont plus contraignantes. Si tu ne veux pas suivre les versions, reste sur le Play Store pour les applications sensibles.
